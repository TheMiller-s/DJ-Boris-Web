# Plataforma Web Oficial — DJ NOIR // The Resident

Una plataforma web interactiva de alto impacto y estética de lujo (*Nightlife Luxury Edition*) diseñada para presentar la trayectoria de más de 25 años del DJ, conectar en vivo con el público del bar o evento mediante código QR, gestionar dinámicamente los géneros de la noche y recibir peticiones de canciones en orden estricto con opción condicional de versiones musicales y salto de regla VIP con aporte.

---

---

### 2. El Sonido de Esta Noche ("Curaduría Musical en Vivo")
- Muestra la fecha de hoy y el local actual (ej. *Casa Cabaña — Arcos Plaza, Samborondón*).
- Despliega las etiquetas de los géneros seleccionados para hoy (ej. *Afro House, Melodic Techno, Nu-Disco, Latin Grooves*).
- **Actualización Inmediata**: El DJ puede modificar los géneros y notas de ambiente en 5 segundos desde el **Modo Cabina**.

---

### 3. Sistema Interactivo de Peticiones de Canciones
- **Cola en Vivo Enumerada (#1, #2, #3...)**: Cada solicitud entra con un número de turno estricto y visible para todo el bar.
- **Reglas Claras**:
  - *Regla General*: Las canciones deben armonizar con los géneros de la noche.
  - *Salto de Regla VIP ($ Aporte al DJ)*: Interruptor para temas fuera del género de hoy con un aporte al DJ para evaluar mezclarlo.
- **Selector Condicional de Versión Musical**:
  - **Versión Original**: El campo para escribir queda completamente oculto y no se solicita nada adicional.
  - **Versión de Preferencia**: Despliega suavemente un campo obligatorio para detallar la versión deseada (*Remix de Fisher, VIP Edit, Versión Acústica, Extended, etc.*).
- **Feedback Háptico y Notificaciones Toast** al enviar la canción a cabina.

---

### 4. Código QR para Mesas & Impresión
- **Generación Local sin Internet**: Genera el código QR al instante con la URL de la página.
- **Descarga en Alta Definición (PNG)**: Crea una tarjeta gráfica de lujo lista para redes o diseño gráfico.
- **Imprimir Caballete de Mesa**: Formato listo para imprimir en tamaño A5/A6 con doble marco dorado y llamadas a la acción para colocar en acrílicos sobre las mesas o la barra del bar.

---

### 5. Modo Cabina (Panel Privado del DJ)
- Acceso rápido desde el botón **"Cabina DJ"** en la barra superior o footer.
- Protegido por PIN de 4 dígitos (**PIN por defecto: `1234`**).
- Permite:
  - Cambiar el nombre del local / evento de hoy.
  - Activar o desactivar géneros con un solo toque o agregar géneros nuevos.
  - Modificar el estado de las peticiones en vivo (*"🔥 Tocar Ahora"*, *"✓ Aceptar"*, *"✨ Completada"*, *"✕ Eliminar"*).
  - Botón *"Reiniciar Noche"* para limpiar la cola al iniciar una nueva fecha.

---

## 🚀 Cómo Usarlo

1. **Abrir localmente**: Haz doble clic en `index.html` en tu navegador preferido (Google Chrome, Microsoft Edge, Safari, Firefox).
2. **Subir a la web**: Puedes alojar esta carpeta en cualquier servicio de hosting estático gratuito como:
   - GitHub Pages
   - Netlify
   - Vercel
   - Tu propio dominio web (ej. `djnoir.com`)
3. **Imprimir el código**:
   - Ve a la sección **"Código QR"** en la página.
   - Haz clic en **"Imprimir Caballete de Mesa"** o pulsa `Ctrl + P`. La hoja saldrá formateada exclusivamente con el cartel elegante para las mesas del bar.
